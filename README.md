
# HR Analytics Dashboard

This project presents an interactive *HR Analytics Dashboard* designed to analyze and visualize employee attrition patterns. The dashboard aims to assist HR departments in identifying key trends and making data-driven workforce decisions.

## Dashboard Overview

The dashboard includes the following insights:

- *Total Employees*: 1470  
- *Attrition Count*: 237  
- *Attrition Rate*: 16.1%  
- *Average Age*: 37  
- *Average Tenure*: 7 years  
- *Average Salary*: 6.5K

## Visualizations

The dashboard includes charts and graphs that analyze attrition by:

- *Education Field* (e.g., Life Sciences, Technical, Marketing, Medical)
- *Age Group* (e.g., 18–25, 26–35, etc.)
- *Salary Slab* (e.g., up to 5K, 5K–10K, etc.)
- *Job Role* (e.g., Sales Executive, Research Scientist, Laboratory Technician)
- *Gender*
- *Years at Company*

## Objective

The purpose of this dashboard is to provide a comprehensive visual overview of attrition data, enabling HR teams to:

- Identify high-risk groups
- Discover potential causes of attrition
- Support strategic planning for talent retention
